# Employee Management System in C

## Overview

A simple Employee Management System developed in C using structures
and binary file handling.

The system performs CRUD operations on employee records using
Employee ID as the identifier.

## Features

- Create employee records
- Read employee records
- Update employee records using Employee ID
- Delete employee records using Employee ID
- Store employee records in a binary file
- Directly update a selected record without rewriting the complete file

## Concepts Used

- C Programming
- Structures
- Binary File Handling
- fread()
- fwrite()
- fseek()
- CRUD Operations
- File Handling
